# grokbot-wechat-setup-skill

A Grok Bot skill that walks a new user through connecting WeChat (ClawBot / iLink) to their Grok Bot: scan-to-bind with the QR sent in chat, inbound webhook setup (desktop only), forwarder, watchdog, and a plain-language wrap-up.

Skill: `wechat-grok-bot-config/SKILL.md`. Bridge code: https://github.com/psylch/grokbot-wechat
